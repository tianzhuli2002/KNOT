# ttbar2L data-contract audit

The audit was run against the configured canonical file
`data/real/ttbar2L_canonical.h5` using `configs/experiments/ttbar2L.yaml` and
streaming chunks. The full machine-readable result is kept outside the
repository during validation; the figures below are the compact result to keep
with the analysis record.

## Retained-object and truth support

| quantity | value |
|---|---:|
| canonical events inspected | 3,921,094 |
| events with `njet > 8` | 5,666 (0.14450%) |
| electron-side truth b outside retained eight jets | 275 (0.007013%) |
| muon-side truth b outside retained eight jets | 272 (0.006937%) |
| either truth b outside retained eight jets | 543 (0.013848%) |
| both truth b roles represented in retained inputs | 3,920,551 (99.98615%) |

For `njet <= 8`, all audited events were reconstructable. The reconstructable
fraction was 0.93057 at njet=9, 0.84164 at njet=10, 0.86532 at njet=11,
0.66667 at njet=12, 0.54167 at njet=13, 0.40000 at njet=14 and 0.50000 at
njet=15. The high-multiplicity tail is small, so this audit does not justify
changing the maintained eight-jet input cap; it does require the support and
Njet stratifications to remain visible in study reports.

## Active input checks

All active input fields were finite: there were zero NaN/Inf values. Jet,
electron, muon and MET kinematics were within their declared finite physical
domains and declared min/max scaler ranges. The only declared-range excess was
`GLOBAL.njet`: 5,666 events are above the nominal `[0, 8]` min-max range, as
expected from the retained-object audit. No truth-derived model input was
found.

Representative extrema were:

| input group | field | minimum | maximum | zero fraction |
|---|---|---:|---:|---:|
| JET | btag | 1 | 6 | 0 |
| JET | eta | -2.5000 | 2.5000 | 0 |
| JET | pt | 20.0 | 1901.1 | 0 |
| ELECTRON | eta | -2.4700 | 2.4700 | 0 |
| MUON | eta | -2.5000 | 2.5000 | 0 |
| MET | pt | 20.0 | 1110.2 | 0 |
| GLOBAL | njet | 2 | 15 | 0 |

Integer/count fields have their expected zero fractions; the all-zero jet
charge field is retained as a data fact, not silently replaced. Quantiles and
variances are available in the streamed audit JSON generated by
`scripts/audit_data_contract.py`.

The canonical eight-jet choice is retained. Events losing a truth-role jet are
not silently repaired or dropped by this audit; the existing reconstructability
and support semantics report them explicitly.
